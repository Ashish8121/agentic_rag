# Agentic RAG for Indian IT Sector Analysis

A RAG system for Indian IT companies (TCS, Infosys, Wipro) that answers 
multi-hop questions across annual reports and proves its reliability with 
RAGAS evaluation.

## Status
Phase 0 complete — building Phase 1 (ingestion)

## Stack
- LLM: Groq (llama-3.3-70b)
- Embeddings: Ollama (bge-m3)
- Vector DB: Chroma
- Orchestration: LangGraph
- API: FastAPI
- Evaluation: RAGAS
